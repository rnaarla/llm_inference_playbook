# Roadmap

## Near Term

- Harden offline CI and policy checks.
- Add more safe examples for common Gateway API controllers.
- Expand placeholder/config generation guidance.
- Add local mock deployment that does not require GPUs.

## Medium Term

- Add controller-specific gateway mappings for kgateway and Envoy Gateway.
- Add optional ephemeral cluster checks with kind/k3d.
- Add public examples of redacted GPU validation outputs.
- Expand MoE companion with more topology examples.

## Long Term

- Publish versioned releases.
- Add docs site.
- Add release automation.
- Add community-submitted profile validation registry.

## Non-Goals

- Operating hosted inference infrastructure for users.
- Shipping real credentials, environment overlays, or production endpoints.
- Claiming fleet validation without user-provided evidence.
