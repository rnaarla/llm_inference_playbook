# Model Registry, Signing, and Promotion

This scaffold keeps model and adapter release metadata outside source control
while defining the artifact contract that deployment consumes.

## Artifact Layout

```text
<registry-host>/models/<model-name>@sha256:<digest>
<registry-host>/adapters/<adapter-name>@sha256:<digest>
```

Tags may be used during build, but promotion must write digest-pinned references
into the private environment overlay. Runtime pulls should use the approved
digest from promotion metadata, not mutable tags.

## Required Inputs

| Input | Source |
|---|---|
| `ARTIFACT` | OCI model or adapter reference |
| `COSIGN_KEY` | KMS URI or key path from CI secrets |
| `SBOM` | SPDX predicate generated by the build pipeline |
| `PROVENANCE` | SLSA provenance predicate generated by CI |
| `MODEL_CARD` | Completed Markdown model card for release docs |
| `MODEL_CARD_PREDICATE` | JSON predicate linking the published model card |
| `PROMOTION_METADATA` | Promotion decision metadata |
| `PROMOTION_PREDICATE` | JSON predicate summarizing the promotion decision |

## Signing Flow

```bash
ARTIFACT=REPLACE_WITH_REGISTRY_HOST/models/REPLACE_WITH_MODEL@REPLACE_WITH_APPROVED_MODEL_DIGEST \
COSIGN_KEY=REPLACE_WITH_COSIGN_KEY_URI \
SBOM=sbom.spdx.json \
PROVENANCE=provenance.intoto.jsonl \
MODEL_CARD=model_card.md \
MODEL_CARD_PREDICATE=model_card.predicate.json \
PROMOTION_METADATA=promotion.yaml \
PROMOTION_PREDICATE=promotion.predicate.json \
bash sign_and_attest.sh
```

The script signs the artifact and attaches SBOM, SLSA provenance, model-card,
and promotion predicates when present. Missing optional predicates are reported
as warnings so CI can decide whether to fail earlier in the release workflow.

## Promotion Contract

Promotion metadata is the bridge between eval gates and runtime verification.
The promoted environment overlay must set:

- `model.artifact` to the digest-pinned artifact reference.
- `modelPuller.verification.approvedDigest` to the approved digest.
- `modelPuller.cosignPublicKeySecret` to the public verification key Secret.
- LoRA adapter entries to digest-pinned adapter references when LoRA is enabled.

Unsigned or mutable references must not be promoted to staging or production.
